# Support

For bug reports and feature requests, open an issue at:

https://github.com/wsyzxjn/maimai-chart-preview/issues

When reporting a playback problem, include:

- VS Code version and operating system
- Extension version
- A small, reproducible `.simai`, `maidata.txt`, or `.ma2` example
- Whether the problem affects accompaniment, hit sounds, or both
- Any messages shown in the VS Code Output or Problems panel

Please do not include private charts, account credentials, or copyrighted audio files in an issue.
